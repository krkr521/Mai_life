# 主动私聊中的双向交流

生活、创作和见闻契机提供一个开场由头，Planner也可以选择关心对方的安排、心情、兴趣和未完话题，无须先汇报自己的事情。
同一份引导进入Planner和Replyer，按语境决定是否接一个容易回答的问题，不强制每条带问号，不固定追加“你在干嘛”。

主动轮仅携带当前收信人最近3天至多4条真实私聊摘要，以及其最近3次已成功收到的主动开场；保留时间，防止把旧安排当成当前状态。
原聊天中已有答案的事不反复问；未知近况保持询问，不虚构对方的经历，不把八千代所在地的天气、日程套到对方身上。
历史消息按引用数据使用，其他用户的记录、普通被动回复、转述和其他插件任务不进入这个补充块。

原有每日额度、错开发送、睡眠、免打扰、临时暂停、身份与隐私边界不变。
Decision继续审核实际正文；给重复的旧趣事加一句“你呢”仍可被判重，真正围绕对方的新话题可以放行。
